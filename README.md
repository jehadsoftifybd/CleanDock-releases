# CleanDock

**A smart dock for Windows 11 and 10.** CleanDock replaces the taskbar with one Liquid Glass dock that holds your apps and 115 live widgets, plus 26 widgets for the desktop. Free, and fully reversible: quitting brings the taskbar back.

🌐 **Website:** [cleandock.site](https://cleandock.site)

## What you get

- A dock on any screen edge, in Glass, Slate, Paper or Midnight style
- 115 live dock widgets: system, weather, music, focus timers, revenue, AI usage and more
- 26 desktop widgets with light and dark styles
- CleanDock Start, Files, Notes and Screenshot, in the same glass

Windows 11 and Windows 10, 64-bit.
